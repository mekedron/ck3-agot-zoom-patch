AGOT Patch for Smooth Zoom Transitions

Makes https://steamcommunity.com/sharedfiles/filedetails/?id=3800395737 work on the map of A Game of Thrones. Without it the base mod, loaded below AGOT, makes every holding model on the AGOT map vanish on zoom step 8 — long before the realm colours start filling the map — and leaves AGOT's roads, special buildings and animals on layers that its table does not declare.

WHY AGOT NEEDS A PATCH

Smooth Zoom Transitions is tuned for vanilla's zoom and ships a full copy of the vanilla map object layer table with its three layers moved off zoom step 9. AGOT replaces the same file and the camera behind it, and the two do not agree:

- vanilla unloads the holding models on step 9; the base mod moves that to 8; AGOT keeps them until step 16
- AGOT's table has seven layers, not three: it adds its special buildings, two road layers and its animals
- AGOT uses its own camera heights (ZOOM_STEPS): step 8 is 250 units up on AGOT against 344 in vanilla
- AGOT shows the large map names from step 12; the base mod sets 11

So with AGOT above the base mod, the towns and villages disappear on step 8 from a map that is still plain terrain (AGOT's colour overlay only starts on step 9), and the 64 special buildings, 74 road objects and 21 animals sit on undeclared layers.

WHAT THE PATCH DOES

AGOT's own tables, with the base mod's idea applied to AGOT's numbers: nothing that AGOT unloads together with the two low tree layers on step 9 stays there, and nothing AGOT keeps until step 16 is touched.

- activities unload on step 7 instead of 9, animals on 8, armies on 10; the four building and road layers stay on 16, exactly as AGOT has them
- coast foam moves to step 7 and the mountain effects to 8 (the base mod uses 6 and 7; AGOT's camera is lower at the same step, so the same heights are one step later)
- the large map names come back on step 12, AGOT's value

The rest of the base mod applies to AGOT unchanged: the halved per-frame mesh budget, the colour overlay start moved to step 10, the fort and raid icons, the flat map icon work, the border update interval and the cheaper name placement search all override keys that AGOT keeps at the vanilla values. That is why the base mod must stay enabled.

LOAD ORDER

- A Game of Thrones
- Smooth Zoom Transitions — anywhere, above or below AGOT
- AGOT Patch for Smooth Zoom Transitions — below AGOT

ULTRAWIDE EXTRA

The base mod's opt-in file cuts the map name draw radius from vanilla's 12000 to 9000; AGOT sets 20000 for its larger map, so that file would cut it by more than half here. The patch ships its own opt-in file with 15000 instead; see the GitHub readme for how to switch it on.

NOTES

- Graphics-only: no gameplay, script or history files are changed, so ironman and achievements are unaffected
- Safe to add or remove at any time, including mid-campaign
- No shaders are touched, so there is no recompile
- Built for CK3 1.19.x, AGOT 0.5.2.1 and Smooth Zoom Transitions 1.0

COMPATIBILITY

Two full replacements of AGOT's game object layer table and the effect layer table; they conflict with any other mod that changes those two files on AGOT. One defines file that only sets the map name step.

[h1]AGOT Patch for Smooth Zoom Transitions[/h1]

[b]Guide:[/b] [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3800254441]CK3 on a potato PC: a locked 60 FPS, and the map still looks sharp[/url] — the settings and mods this belongs to.

Makes [url=https://steamcommunity.com/sharedfiles/filedetails/?id=3800395737]Smooth Zoom Transitions[/url] work on the map of [b]A Game of Thrones[/b]. Without it the base mod, loaded below AGOT, makes every holding model on the AGOT map vanish on zoom step 8 — long before the realm colours start filling the map — and leaves AGOT's roads, special buildings and animals on layers that its table does not declare. It also stops AGOT drawing every holding model until step 16, far into the painted political map.

[h2]Why AGOT needs a patch[/h2]

Smooth Zoom Transitions is tuned for vanilla's zoom and ships a full copy of the vanilla map object layer table with its three layers moved off zoom step 9. AGOT replaces the same file and the camera behind it, and the two do not agree:

[list]
[*]vanilla unloads the holding models on step 9; the base mod moves that to 8; [b]AGOT keeps them until step 16[/b]
[*]AGOT's table has seven layers, not three: it adds its special buildings, two road layers and its animals
[*]AGOT uses its own camera heights (ZOOM_STEPS): step 8 is 250 units up on AGOT against 344 in vanilla
[*]AGOT shows the large map names from step 12; the base mod sets 11
[/list]

So with AGOT above the base mod, the towns and villages disappear on step 8 from a map that is still plain terrain (AGOT's colour overlay only starts on step 9), and the 64 special buildings, 74 road objects and 21 animals sit on undeclared layers.

[h2]What the patch does[/h2]

AGOT's own tables, with the base mod's idea applied to AGOT's numbers: nothing that AGOT unloads together with the two low tree layers on step 9 stays there, and the holding models leave when the realm colours arrive.

[list]
[*]activities unload on step 7 instead of 9, animals on 8, armies on 10
[*]the holding models (every castle, city and temple) unload on step 12, where the colour overlay becomes visible (it starts on 10 but is nearly transparent for two steps), instead of AGOT's 16: at that height the map is a painted political map and the thousands of meshes still alive on it are what took a 4 GB laptop GPU from 60 to 17 FPS. AGOT's hand placed cities (Braavos, Gulltown, Lannisport, Tyrosh, Oldtown, White Harbor...) and its bridges and Valyrian roads are map objects on AGOT's own layers and go on the same step, so no town outlives the colour fill; the skybox that shared their layer keeps AGOT's step 16 on a layer of its own
[*]coast foam moves to step 7 and the mountain effects to 8 (the base mod uses 6 and 7; AGOT's camera is lower at the same step, so the same heights are one step later)
[*]the large map names come back on step 12, AGOT's value
[/list]

The rest of the base mod applies to AGOT unchanged: the halved per-frame mesh budget, the colour overlay start moved to step 10, the fort and raid icons, the flat map icon work, the border update interval and the cheaper name placement search all override keys that AGOT keeps at the vanilla values. That is why the base mod must stay enabled.

[h2]Load order[/h2]

[list]
[*]A Game of Thrones
[*]Smooth Zoom Transitions — anywhere, above or below AGOT
[*]AGOT Patch for Smooth Zoom Transitions — [b]below AGOT[/b]
[/list]

[h2]Ultrawide extra[/h2]

The base mod's opt-in file cuts the map name draw radius from vanilla's 12000 to 9000; AGOT sets 20000 for its larger map, so that file would cut it by more than half here. The patch ships its own opt-in file with 15000 instead; see the GitHub readme for how to switch it on.

[h2]Notes[/h2]

[list]
[*]Graphics-only: no gameplay, script or history files are changed, so ironman and achievements are unaffected
[*]Safe to add or remove at any time, including mid-campaign
[*]No shaders are touched, so there is no recompile
[*]Built for CK3 1.19.x, AGOT 0.5.2.1 and Smooth Zoom Transitions 1.0
[/list]

[h2]Compatibility[/h2]

Three full replacements: AGOT's game object layer table, the effect layer table and AGOT's skybox object file; they conflict with any other mod that changes those files on AGOT. One defines file that only sets the map name step. 3D landmarks other mods add as building assets (COW-AGOT's Maidenpool, say) are drawn by the holding system and are outside this patch's reach.

# Overrides A Game of Thrones' gfx/map/map_object_data/game_object_layers.txt
# (AGOT 0.5.2.1), which itself replaces the vanilla file.
#
# Smooth Zoom Transitions ships the *vanilla* table with three layers, moved
# off zoom step 9. Under AGOT that copy is wrong twice: AGOT keeps every
# holding model up to step 16, and it declares four layers of its own
# (special buildings, roads, animals) that the vanilla table does not know.
# AGOT also uses its own camera heights, so "step 8" is 250 units up here
# against 344 in vanilla.
#
# This table is AGOT's, with the same idea applied to AGOT's numbers: what
# AGOT unloads together with the two low tree layers on step 9 moves down to
# 7 and 8, armies move up to 10. The holding models (building_layer, every
# castle, city and temple on the map) leave on step 12, where the realm colour
# overlay becomes visible (it starts on 10 but is nearly transparent for two
# steps): AGOT's 16 keeps thousands of meshes alive over an area that has long
# turned into a painted political map, and it costs frame rate exactly there. AGOT's own building layer (Braavos, Gulltown, Lannisport,
# Tyrosh, Oldtown, White Harbor, Pyke, the Wall's castles) and its road and
# bridge layers go on the same step, so no town outlives the colour fill.
#
# AGOT's skybox mesh sits on AGOT_building_layer too; it moves to a layer of
# its own here (skyx_skybox.txt) so that it keeps AGOT's step 16.
#
#   layer                 AGOT  here   camera height (AGOT ZOOM_STEPS)
#   activities_layer         9     7   210
#   AGOT_animal_layer        9     8   250
#   AGOT_building_layer     16    12   468
#   AGOT_low_roads          16    12   468
#   AGOT_roads              16    12   468
